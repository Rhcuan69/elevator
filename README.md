The funniest thing an elevator would say if it could talk, in its own voice: you pressed the button fourteen times in a row, it heard you the first time — it's an elevator, not a miracle worker. Pure-stdlib Python entry for make.fun's "What the Elevator Would Say" bounty ($2 USDC, winner-take-all). The program writes the line to `entry.txt`, deterministically, with no dependencies beyond vanilla Python.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
